# 日本語 UI と実 API のブラウザー検収

日本語 UI と内蔵の架空の中国語社員手引きを使用。text-embedding-3-small、Luna Generator/Verifier、strict、900/0、Exact。凍結評価セットとは別の記録です。

- 実索引を完了：3 ページ / 3 chunks、次元 1536。
- 日本語でデモ手引きを明示して質問すると、3 営業日前に OA 提出し直属上司が承認するとの回答を生成。主張は実行時検証を通過。
- 引用パネルに PDF の 2 ページ目、中国語原文、日本語リンク、`#page=2` を表示。原本は HTTP 200 で PDF。
- 設定保存通知、動的ナビゲーション見出し、引用パネルの閉じるボタンを日本語化。文書原文・ファイル名は元言語を保持。
- 初回の範囲不明な質問は insufficient_evidence。そこから一般的回答能力を断定せず、両リクエストと実費用を保存。

token、費用、時間、フロントソースのハッシュは [JSON](live-ui-smoke.json)。UI と処理経路の検収であり、汎化精度の証明ではありません。
