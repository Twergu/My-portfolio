# Agent 第三阶段：页面、多轮交互与证据展示

状态：本阶段实现与本地验收完成，按用户要求停在此阶段。前两阶段的通用编排、工具和严格依据验证现可直接从聊天页使用。

## 使用方法

运行 `python run.py`，打开 `http://127.0.0.1:8000/`，选择 **业务 Agent**。先准备有文字层、索引就绪且有访问权限的 PDF，并在模型设置中启用 API 模式。普通知识问答继续使用原 RAG 接口。

描述要办理的事项以及已知条件；页面会展示回答或需要补充的问题。等待补充时，在同一输入框回复即可。要更换文档范围或开始另一件事，先点击 **结束任务** 或 **发起新问答**。页面只提供判断与办理指导，不会提交申请或执行外部操作。

## 修改与效果

| 修改 | 效果 |
| --- | --- |
| 通用业务入口 | “知识问答 / 业务 Agent”可切换；采购、培训和条件确认仅作为提问示例，没有把业务限定为请假。 |
| 多轮补充 | `needs_input` 显示问题与任务提示；回复发送到原任务，只包含新增文本，不重建 Planner 上下文。 |
| 范围锁定与取消 | 在运行中或等待补充时锁定文档、筛选和模式。取消成功才清除句柄；404 可安全结束，409/网络失败保留任务供重试。 |
| 三类来源 | 分开显示文档、工具、用户信息。PDF 可查看物理页；工具展示运算输入和结果，自述注明尚未由业务系统核实。 |
| 真实执行记录 | 只展示后端返回的实际工具完成/失败、追问和验证事件；同步请求结束后显示，不伪造实时步骤。 |
| 验证状态 | 未通过引用或断言检查时显示拦截状态，候选回答不展示；模拟日历与用户自述的限制保留。 |
| 中日文与响应式 | 模式、追问、错误、来源、工具字段和执行记录均有中日文；模型答案/原文保持原样。检查了 390px 手机宽度，无横向溢出。 |
| 登录隔离 | 退出登录清空消息、草稿、筛选、来源和任务；迟到的响应不恢复旧内容，旧请求的 401 不注销新身份。任务句柄不写入 localStorage。 |
| 工程验证 | Node 内置测试覆盖任务路由、续接、取消、过期、并发、身份隔离、XSS 转义、来源分类；CI 已加入动态前端测试报告。 |

## 实际浏览器检查

使用隔离 SQLite、[虚构测试政策](../evals/agent-workflows.json)，重新实际索引 PDF。Embedding、Planner、Generator 和 Verifier 均调用配置的真实模型；没有改动用户原有文档。模型为 gpt-5.6-luna / text-embedding-3-small；场景为少量功能检查，未经人工审核，也不是独立质量 benchmark。

| 页面场景 | 观察到的实际结果 | 本次输入耗时 |
| --- | --- | ---: |
| 中文采购 | Knowledge Search + Calculator，3 × 1200 = 3600 日元；回答 5/5 条断言通过，三类来源可打开，执行记录正确。 | 22.52 秒 |
| 日文补助追问 | 正确询问全职、现场办公天数及材料；锁定检索范围，补充信息续接同一任务。 | 8.67 秒 |
| 日文补助续接 | **后续回答未通过严格验证，仅 1/4 条断言通过，回答被隐藏。** 页面正常解除等待并展示拦截状态。 | 15.74 秒 |
| 日文培训 | Calendar 计算 2026-10-12 提前三个自然日为 2026-10-09，列出规定材料；4/4 条断言通过。 | 16.50 秒 |
| 日文原有 RAG | 切回普通问答，正确回答培训材料并引用 PDF 第 2 页；1/1 条断言通过。 | 4.98 秒 |
| 中文任务取消 | 实际模型先追问；点击结束后服务端取消成功，页面标记已结束并解锁范围与模式。 | 追问 4.99 秒 |

日文续接说明：这里确认的是多轮界面与拦截流程正确，不能宣称该次业务问答成功，也尚未区分 Generator 错误与 Verifier 误拒答。应在后续质量校准中单独诊断；没有通过降低 strict 强度来使这条样例变绿。真实回答的随机性也意味着第二阶段四例通过不保证每次重跑通过。

用量原始记录：[浏览器调用指标](../reports/agent-stage3/browser-api-metrics.json)。成功启动预览服务后记录到索引及六次问答输入，估算合计 **USD 0.01279446**，包含被拦截回答与追问。单价来自配置，不等于服务商账单；没有把等待用户输入算入模型延迟。最初沙箱中的索引连接失败后，获准在沙箱外运行并从页面重建索引。

## 验收与当前边界

- 前端自动测试数量由 `python -m scripts.check_frontend` 从 TAP 输出生成：[JSON](../reports/agent-stage3/frontend-tests.json)、[原始 TAP](../reports/agent-stage3/frontend-tests.tap)。需 Node.js 24，无 npm 依赖。
- Python 回归与覆盖率：[动态测试报告](../reports/tests.md)。本机 PostgreSQL 测试未配置数据库而跳过，不算通过。Ruff check/format 与三个前端脚本语法检查通过。
- 当前浏览器检查无控制台 error。自动测试还覆盖浏览器未逐一模拟的身份切换、401、404、409 和恶意来源文本。
- CI 工作流已加入前端测试，但本阶段没有声称新增 Agent 已通过远程 CI、Docker 或 PostgreSQL 验收。
- 页面刷新会丢失本地对话与任务句柄；服务器等待任务从创建起保留 15 分钟，单进程重启即失效。结束按钮只取消等待中的任务，不能中断正在进行的模型请求。
- 日历的工作日范围仍为显式模拟数据；没有新增 HR、真实日历、外部写入工具、Agent 审批或 Human-in-the-loop。
