# Agent 单进程运行边界

本阶段不引入 Redis、分布式队列或持久化对话。每个 Uvicorn 进程拥有自己的 `AgentService`；当前请运行 **一个 worker / 一个实例**。多 worker 随机路由会找不到其他进程的任务，粘性路由也不等于持久化保证。

| 行为 | 当前合同 |
| --- | --- |
| 会话存储 | 内存，仅保存 running / needs_input；最终答案或异常后释放任务 |
| 所有者 | 随机 task_id 绑定服务器认证用户；他人访问返回 404 |
| TTL | 创建起 900 秒的绝对期限，补充信息不会延长；清理在后续请求时惰性进行 |
| 到期 | 空闲任务续接/取消返回 404；过慢澄清结束时若已到期，返回 task_expired，不给出无效续接句柄 |
| 正在运行 | TTL 不是硬中断超时；忙任务计入容量且不能被另一请求清走。已经发出的模型调用不会被强制撤销 |
| 并发 | 全进程最多 100 个活跃任务、每用户最多 4 个；等待补充和忙任务都占额度，超额 429 |
| 同任务并发 | 锁内占用 busy 标志，重复 reply / cancel 返回 409；不会启动第二套 Planner/工具调用 |
| 取消 | 仅取消等待补充的任务；已执行只读工具和模型费用不能撤销；正在运行请等待本次操作返回 |
| 关闭浏览器 | HTTP 同步模型调用可能继续；断开连接不能保证取消或退款。任务仍受容量和过期约束 |
| 重启/崩溃 | 待续接任务丢失，旧 task_id 返回 404；数据库中的文档、向量、ACL 不随内存任务消失 |
| 权限/证据变化 | 每次模型调用前及返回前复查身份、ACL、设置、文档/分块。变化使旧任务失效，需重新开始 |
| 操作预算 | 默认最多 8 次 Planner、6 次工具尝试、4 轮用户输入；续接不重置预算。输入/证据也有长度上限 |

这些是进程内资源边界，不是分布式限流、耐久任务队列或全局 API 花费上限。多个用户仍可能并发调用模型；Provider 的超时/有限重试独立于任务 TTL。当前 Agent 只有只读检索和确定性计算/日期工具，没有邮件、审批、写库等业务写操作。

新增测试用真实线程同时发起同一任务 reply / cancel，验证只有一次模型路径进入。还覆盖 TTL 边界、不滑动续期、异常释放容量、跨用户全局容量、重启丢状态及过期取消的一致性。数据库合同同时在 SQLite 和 CI 中的真实 PostgreSQL/pgvector 执行。

## Policy Evidence 边界

Agent 的自由文本断言必须引用一个当前适用的 Document Evidence：真实检索的文档/分块/物理页身份，`policy_status=current`，且没有与任务日期冲突的生效区间。上传后仍为 `unclassified` 的文档需要在文档面板确认政策状态；普通 RAG 路径保持原行为。显式 `filters.as_of` 可使用覆盖该日期的已归档政策；草案不能作为正式业务许可依据。

工具来源与用户自述保持独立。计算项应由 Generator 返回 `calculation_source_id`，服务器从该工具的结构化结果生成中日英断言和固定引用；模型不能覆盖文字、数字、单位或来源。单位必须有带相应操作数的原文出处，不做自动换算或量纲推断。自由文本中没有适用文档的业务许可依然拦截；User Input 不单独建立规则。所有生成内容仍进入 Strict/all。详见[本轮修改报告](agent-followup-report.md)。

确定性检查证明来源类型和有效范围，不能证明每个自然语言推论。因此所有接受的候选仍进入 `strict + all`：验证 quote、数字、条件、否定、适用范围和同一 claim 的完整证据。即使引用了一个有效但无关的文档，也不能绕过语义 Verifier。其余事实/相关性仍受模型误判风险影响。
