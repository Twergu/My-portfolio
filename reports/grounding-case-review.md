# 根拠検証の不一致：原文との照合

凍結した 900/0 strict test の `unsupported_answer` 3 件が対象です。保存した原文を使う Codex の事後分析で、独立した人手ラベルではありません。モデル再呼び出し、採点変更、test に基づくプロンプト調整はしていません。[問題別 JSON](chunks-api/chunk-api-selected-test.json)を参照してください。

自動 Judge は遮断候補 3 件をすべて正確・根拠ありとしましたが、3 回の遮断がすべて誤りという意味ではありません。`grounding_rejected_correct_and_grounded = 1.0, n=3` は自動診断値です。
