# 日文真实 API 浏览器验收

范围：本机浏览器 + 自带虚构中文员工手册。使用 text-embedding-3-small、Luna Generator/Verifier、strict、900/0、Exact；与冻结评估集分开记录。

- 真实索引完成，3 页/3 chunks，向量维度 1536。
- 日文问题明确询问演示手册后，回答为提前 3 个工作日在 OA 提交、直属经理审批；两个断言均通过运行时验证。
- 点击引用显示原 PDF 第 2 页的中文原文；引用链接含 `#page=2`，原文件 HTTP 200 且为 PDF。
- 设置保存提示、动态导航标题和引用面板关闭按钮显示日文；文档原文与文件名保留原语言。
- 第一条未明确演示范围的问题返回 insufficient_evidence，未据此认定拒答合理；两条问题的实际费用都保存。

逐操作 token、成本、用时及前端源码摘要见 [JSON](live-ui-smoke.json)。这是浏览器流程验收，不是生产准确率证明。
